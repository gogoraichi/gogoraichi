# 把 AI、設計與工作流，做成可執行的作品

我是 Nick，氖機智造（Neohime）的主理人。

我關注 AI 創作、設計與科技如何真正進入日常工作，把模糊的想法整理成可執行的工作流、內容與工具。

## 我正在做的事

- 透過 [氖機智造](https://neohime.com/) 分享 AI 創作、設計、科技與實際可用的工作方法。
- 在 [NeoCaptain Labs](https://github.com/Neo-Captain-Labs) 公開可重複使用的工具規格與工作流。
- 持續研究如何讓 AI 協助篩選資訊、整理脈絡，讓人把注意力留給真正值得判斷的事。

## 公開作品

### Knowledge Radar｜知識雷達

把 RSS、電子報與其他閱讀來源集中，再由 AI 依照你的規則初步篩選、去除重複訊息，最後把值得你注意的內容送到你真正會查看的地方。

[查看完整規格與建置任務書 →](https://github.com/Neo-Captain-Labs/knowledge-radar)
